# Computer Architecture: 24-class plan (24 classes x 60 minutes)

Progression: basic computer organization -> ISA -> pipelining -> ILP -> memory -> storage/I/O -> multiprocessors -> arithmetic/vector processing -> RISC/CISC.

Each class becomes one interactive lesson (`content/computer-architecture/NN-<topic>.lesson.json`, 60 minutes, level Beginner unless the author says otherwise). The author sends the plan part by part; build only the classes that have been described, and add the next parts here as they arrive.

## Part 1: Fundamentals of Computer Design

| Class | Topic | Main contents |
| --- | --- | --- |
| 1 | Introduction to Computer Architecture | What is computer architecture? Computer organization vs architecture, components of a computer, CPU, memory, I/O, system interconnection, role of a computer architect |
| 2 | Tasks of a Computer Architect + Technology Trends | What architects actually design, design constraints, technology evolution, Moore's Law, transistor trends, semiconductor technology, power/energy trends |
| 3 | Cost, Performance & Quantitative Principles | Cost trends, performance vs cost, response time, throughput, CPU performance equation, clock rate, CPI, instruction count, Amdahl's Law |
| 4 | Measuring Computer Performance | Benchmarks, execution time, CPU time, elapsed time, MIPS, FLOPS, speedup, performance comparison, common measurement mistakes |
